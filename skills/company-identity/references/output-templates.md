# 결과물 양식 3종

새 회사 문서를 작성할 때 사용하는 기본 구조. `documents.md`의 저장·기존 문서 보존 규칙과 함께 읽는다.

- 대괄호를 인터뷰 답변·기존 자료·확정한 기준으로 채워 실제 문서로 저장한다. 사용자가 양식을 별도로 요청하지 않았다면 빈 템플릿을 결과물로 내지 않는다.
- 필요한 기준만 행을 추가하고, 해당하지 않는 항목은 생략한다. 확인하지 않은 내용은 가설·미정으로 구분한다.
- 프로젝트 작업 지침은 현재 회사에 적용할 행동과 검토 방법으로 완성한다. 아직 특정 프로젝트가 없어도 목표·자료·산출물을 작업 시작 시 파악하도록 안내하면 된다.
- 회사 문서의 경로는 실제 파일을 읽어 확인한 절대 경로로 채운다. 기존 회사 문서의 이름·위치는 유지한다.

## 1. 회사 방향성 — about-company.md

```markdown
# 회사 방향성

## 회사와 고객

- 회사·활동명: [이름]
- 하는 일: [제공하는 제품·서비스·활동]
- 우선 고객: [가장 먼저 집중할 고객]
- 해결할 문제: [고객이 겪는 구체적인 어려움]
- 고객의 현재 해결 방법: [현재 쓰는 제품·서비스·방식]
- 우리를 선택할 이유: [고객에게 제공할 차이와 근거]

## 존재 이유와 비전

- 비전 한 줄: [사용자가 정하거나 고른 한 문장. 정하지 않았으면 미정]
- 존재 이유: [이 일을 통해 고객에게 주려는 가치]
- 만들고 싶은 변화: [앞으로 고객이나 시장에서 이루고 싶은 변화]

## 핵심 가치

| 가치 | 실제 업무에서 지킬 행동 |
| --- | --- |
| [중요하게 여기는 가치] | [그 가치를 지키는 구체적인 선택·행동] |

## 우선순위와 지양점

- 기준이 충돌하는 상황: [두 가지 가치를 동시에 지키기 어려운 상황]
- 우선할 기준과 이유: [무엇을 우선하고 왜 그렇게 결정했는지]
- 피할 일·표현·약속: [우리 회사가 지양할 방향]

## 아직 정할 내용

- [미정인 내용과 더 확인할 사항]
```

## 2. 업무 사규 — company-rules.md

```markdown
# 업무 사규

## 적용 범위

- 적용할 업무: [이 기준을 사용할 업무]

## 작업·검토 기준

| 적용 상황 | 연결된 회사 방향성 | 지킬 행동 | 결과물에서 확인할 내용 |
| --- | --- | --- | --- |
| [규칙이 필요한 상황] | [가치·우선순위·지양점] | [해야 할 일·피할 일] | [충족 여부를 판단할 근거] |

## 사용자 확인이 필요한 일

- 확인할 상황: [사용자의 판단·승인이 필요한 경우]
- 확인할 내용: [사용자에게 제시할 정보와 결정할 사항]

## 기준 충돌과 예외

- 기준이 충돌할 때: [적용할 우선순위 또는 사용자에게 확인할 사항]
- 예외를 허용할 조건: [허용 조건과 적용 범위]

## 상황별 적용

| 업무 상황 | 선택할 행동 | 적용한 기준 |
| --- | --- | --- |
| [우리 사업에서 실제로 생길 상황] | [이 상황에서 할 일] | [위 규칙 중 판단 근거] |

## 아직 정할 내용

- [미정인 규칙과 더 확인할 사항]
```

## 3. 프로젝트 작업 지침 — project-instructions.md

```markdown
# 프로젝트 작업 지침

## 적용 범위

- 회사·활동: [회사명 또는 활동명]
- 적용할 업무: [회사 기준을 사용할 업무]

## 작업 시작

- 아래 회사 방향성과 업무 사규를 읽고 이번 작업에 적용할 기준을 확인한다.
- 요청과 프로젝트 자료에서 목표·입력 자료·산출물을 파악한다.
- 필요한 정보가 부족하면 사용자에게 결정할 내용을 묻는다.

## 작업 진행

- [인터뷰에서 정한 회사 기준을 적용하는 구체적인 작업 방법]

## 결과 검토

- [업무 사규에 근거해 결과물에서 확인할 내용]

## 판단이 필요한 상황

- [회사 기준상 사용자 확인이 필요한 상황과 확인할 내용]
- 프로젝트 요구사항과 회사 기준이 충돌하면 충돌 내용과 선택지를 사용자에게 확인한다.

## 참고할 회사 문서

- 회사 방향성: [about-company.md의 전체 경로]
- 업무 사규: [company-rules.md의 전체 경로]
```
