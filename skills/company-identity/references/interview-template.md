# 회사 방향성 인터뷰 템플릿

질문과 답변 정리에 사용하는 양식. 현재 답변에 필요한 부분만 채워 사용한다.
진행 규칙은 `interview.md`, 채워진 예시는 `interview-examples.md`를 따른다.

## 1. 첫 질문

이미 소개한 내용은 생략하고, 사업을 이해하는 데 부족한 정보만 묻는다.

```text
어떤 일을 하는지부터 알려 주세요.

1. 어떤 제품이나 서비스를 제공하나요?
2. 주로 누구의 어떤 문제를 해결하나요?
```

## 2. 구체화 질문

가치·비전·우선순위처럼 선택이 필요한 질문에 사용한다. 한 번에 1~2개 주제만 다룬다.

```text
## 질문
[이번에 정할 내용 한 가지를 묻는 질문]

## 상황
[사용자의 사업에서 실제로 생길 만한 상황]

## 답변 예시
1. [첫 번째 선택과 지킬 기준]
2. [다른 선택과 지킬 기준]
3. [필요한 경우 세 번째 선택]

예시를 고르거나 고쳐 답해 주세요. 다른 답이나 미정도 괜찮아요.
```

답변을 받은 뒤 명확한 내용은 반영하고, 모호한 조건만 후속 질문한다.

| 정리할 내용 | 기록 방법 |
| --- | --- |
| 선택한 기준 | 사용자가 선택하거나 수정한 뜻 그대로 |
| 적용 범위 | 어떤 업무·상황에 적용하는지 |
| 미정 | 사용자가 보류한 결정 |
| 다음 질문 | 문서 작성에 필요한 빈틈이 있을 때만 |

## 3. 초안 확인

```text
## 정리한 방향성
- 고객과 해결할 문제: [확인된 내용]
- 만들고 싶은 변화: [확인된 내용]
- 우선할 가치와 지양점: [확인된 내용]

## 업무 기준
- [해당 상황]에서는 [할 행동]을 하고, [결과에서 확인할 내용]을 점검한다.

## 아직 정하지 않은 내용
- [사용자가 보류한 내용이 있을 때만 기재]

답변과 다르게 정리된 부분이 있으면 알려 주세요.
```

확인되지 않은 항목은 질문하거나 미정으로 남긴다. 이미 확인한 결정을 다시 승인받지 않는다.

## 4. 상황 검증

```text
## 상황
[정리된 원칙의 우선순위나 경계를 확인할 업무 상황]

## 질문
이 경우에는 어떻게 진행할까요?

## 답변 예시
1. [원칙에 맞는 선택과 감수할 점]
2. [다른 합리적인 선택과 감수할 점]

예시를 수정하거나 다른 방법을 제안해도 괜찮아요.
```

선택 후에는 해당 기준을 보강하고, 다른 상황에도 같은 해석이 가능한지 확인한다.

## 5. 문서 반영

- 확인한 답변을 `documents.md`의 문서 구성에 반영
- 가설·미정 항목과 확정된 기준 구분
- 저장 후 실제 파일 경로와 남은 질문만 간단히 안내
